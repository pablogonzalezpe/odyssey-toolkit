Odyssey UDP Relay Lab
=====================

Network layout:

  pentester (10.10.10.3)  ---[pentest-net]---  jumpbox (10.10.10.2)  ---[internal-net]---  destiny (10.10.20.2)

Roles:

  pentester  DNS client (dig)
  jumpbox    runs Odyssey UDP relay forwarding port 53 to destiny
  destiny    internal DNS server (dnsmasq) with a custom zone

The pentester has no route to destiny. The jumpbox relays UDP
datagrams on port 53 to the internal DNS server.

Try it:

  dig @10.10.10.2 secret.internal

Expected output (ANSWER SECTION):

  secret.internal.    0    IN    A    10.10.20.99

Key difference from the TCP relay lab:

  DNS uses UDP. The relay receives each datagram, looks up (or creates)
  a NAT session for the source address, forwards the datagram to destiny,
  and sends the response back to the original client. No TCP connection
  is established.
